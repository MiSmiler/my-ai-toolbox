# Python habits

Personal, Python-specific habits on top of the community best-practice baseline.

## Community baseline

- Style: [PEP 8](https://peps.python.org/pep-0008/); ruff (or flake8) for lints, Black / ruff-format for formatting.
- Docstrings: [PEP 257](https://peps.python.org/pep-0257/) conventions.
- Typing: [PEP 484](https://peps.python.org/pep-0484/) annotations on public functions; type-check with mypy or pyright.
- Naming: `snake_case` functions and variables, `PascalCase` classes, `UPPER_SNAKE_CASE` module-level constants.
- Idioms: prefer EAFP (`try`/`except`) over LBYL where it reads clearer; comprehensions over manual loops for mapping and filtering.
